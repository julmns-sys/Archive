# Bob Archive user guide

## First launch

Open **Storage Places** and add where physical books are kept. A bookcase can
have shelves; a suitcase does not need them. Bob Archive suggests the next name
and readable short code automatically. Enable shelves and use **Add Shelf** to
create `Shelf 1`, `Shelf 2`, and so on automatically. Double-click a shelf to
rename it, or select shelves and press **Remove Selected**.

Open **Categories** to add simple groups such as Characters, Science, or Art.
Categories do not move or delete physical books.

Use **Tags** for flexible labels such as `drawings`, `urgent`, or `rescan`.
Tags can be created while adding or editing a book. Type a tag directly into
the main Library search field to find its books. Both `drawings` and
`#drawings` work; there is no separate tag filter.

## Add and read a book

On **Library**, press **+ Add Book**. Enter a title, choose its physical storage
and optional shelf, select categories, and choose one or several PDFs. You can
also drop multiple PDFs onto the window. Drag files inside the PDF list to
choose the order in which their pages will be combined. The import keeps every
selected file unchanged and preserves separate managed copies of all sources.

A printable cover is generated by default. Choose the combined PDF page whose
largest photograph should appear below the centered serif title. The title is
also repeated at the top edge so the same printed sheet can provide a spine
label. Clear **Generate a cover** if the scan already contains its own cover.

Double-click a Library entry to read it. Use Previous/Next, thumbnails, zoom,
Fit Page, or Fit Width.

## Delete books

On **Library**, select one book or use Command-click/Shift-click to select
several books, then press **Delete Selected**. Deletion permanently removes the
catalog entries and all managed PDFs and thumbnails. Type `bob` in lowercase in
the confirmation window to enable the final delete button.

## Edit pages

From an open book, press **Edit Pages**. Drag thumbnails to rearrange them.
Select one to rotate, delete, crop, white out, or draw with a marker.

When editing a book's information, changing its title also updates the title on
its generated cover. Use **Choose New Photo…** in the same dialog to replace the
cover photograph. If the book has no generated cover yet, choosing a photograph
creates one without changing the untouched original PDF.

For Crop, drag the four large blue corner handles to the physical corners of
the scanned paper, then apply. **Reset Page** restores that page from the
untouched imported original when its original page still exists.

## Backup

Open **Backup**, press **Create Backup File**, and save the `.bobbackup` file on
an external drive or in another safe location. Bob Archive writes the file
directly without staging a second copy of the library, and only a complete
backup is finalized. The file is a regular ZIP archive containing every source
file, each current readable PDF, JSON metadata, and the SQLite catalog. Derived
original PDFs are rebuilt from the preserved sources during restore, reducing
the backup size without discarding source material.

To bring the library back, press **Restore Library from Backup**, choose the
`.bobbackup` file, and confirm. The backup is fully checked before it replaces
the current library; after restoration, its books immediately appear on the
Library page.
